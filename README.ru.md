## Что это?

Некоторые файлы на Google Drive можно только **смотреть**: кнопки «Скачать» нет, печать тоже закрыта.

**drivegrab** всё равно их сохраняет. Вставляешь ссылку и получаешь файлы.

- Работает с **одним файлом** или **целой папкой**, включая все подпапки.
- Сохраняет **ту же структуру папок** и упаковывает всё в **.zip**.
- Если файл можно скачать обычным способом, сохраняется оригинал.

## Быстрый старт

**1. Установка** (один раз). Нужен [Python 3.9+](https://www.python.org/downloads/).

```bash
git clone https://github.com/Osmanov2006/drivegrab.git
cd drivegrab
pip install -r requirements.txt
playwright install chromium
```

**2. Запуск**

```bash
python -m drivegrab
```

**3. Вставь ссылку и нажми Enter**

```text
Drive link (empty to quit): https://drive.google.com/drive/folders/1n64NVPN...
```

Откроется окно браузера и начнёт работать само. **Не закрывай его.** Когда всё закончится, файлы будут лежать в папке **`downloads`** рядом с проектом.

## Что пишет в терминале

- **"download is disabled"** значит, файл только для просмотра, и drivegrab собирает его по страницам из превью. Это нормально.
- **"original file saved"** значит, файл можно было скачать, и сохранился оригинал.
- **"failed"** в конце показывает файлы, которые не получилось сохранить. Обычно это видео или файлы без превью.

## Частые вопросы

**Просит войти в аккаунт.**
Файл не публичный. Войди в Google в открывшемся окне браузера и нажми Enter в терминале. Это нужно сделать один раз, вход запоминается.

**Страницы размытые.**
Запусти с окном побольше: `python -m drivegrab --size 2560x1440`

**В PDF нельзя выделить текст.**
View-only файлы собираются из картинок страниц, поэтому текст не выделяется. Если нужен поиск по тексту, прогони файл через [OCRmyPDF](https://github.com/ocrmypdf/OCRmyPDF).

**Можно сразу дать ссылки, без вопроса в терминале?**
Да: `python -m drivegrab <ссылка1> <ссылка2>`

## Что лежит в репозитории

Сама программа находится в папке `drivegrab/`. Остальные файлы — стандартная обвязка, чтобы проект устанавливался и проверялся автоматически.

| Файл | Зачем |
|---|---|
| `drivegrab/grabber.py` | **Основная логика**: открывает Drive, обходит папки, скачивает файлы, собирает страницы |
| `drivegrab/scripts.py` | Небольшие куски JavaScript, которые выполняются на странице Drive и забирают картинки страниц |
| `drivegrab/cli.py` | То, что видно в терминале: ввод ссылки и опции |
| `drivegrab/links.py` | Достаёт ID файла или папки из ссылки |
| `drivegrab/paths.py` | Делает имена файлов безопасными для Windows и не даёт перезаписать файлы |
| `tests/` | Автоматические проверки (тесты) |
| `.github/workflows/ci.yml` | Запускает тесты на GitHub после каждого изменения (зелёный значок CI) |
| `pyproject.toml`, `requirements.txt` | Список зависимостей для `pip install` |

## Пожалуйста, пользуйся честно

drivegrab работает только с файлами, которые ты и так можешь открыть в браузере, и права доступа не обходит. Сохраняй то, что тебе можно хранить, например свои учебные материалы.
