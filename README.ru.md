**drivegrab** скачивает файлы с Google Drive, в том числе те, где владелец отключил скачивание (view-only). Можно дать ссылку на файл или на целую папку. Скрипт обходит все подпапки, сохраняет файлы с той же структурой и упаковывает всё в `.zip`.

Я написал его, потому что материалы курсов в университете (слайды, конспекты, прошлые экзамены) выкладывают в view-only папках по несколько десятков файлов, и сохранять их по одному через консоль браузера было слишком долго.

## Возможности

- **Папки целиком.** Скрипт рекурсивно обходит все вложенные папки, повторяет их структуру и собирает zip.
- **View-only PDF.** Если скачивание закрыто, скрипт листает просмотрщик Drive и собирает PDF из отрисованных страниц.
- **Оригиналы, где можно.** Файлы, которые разрешено скачивать, сохраняются как есть, а не скриншотами.
- **Длинные документы.** Drive выгружает страницы, ушедшие за экран, поэтому каждая страница забирается в момент, когда видна, и потом сортируется по позиции.
- **Запоминает вход.** Войти в Google нужно один раз, профиль браузера сохраняется между запусками.
- **Устойчивость.** Ошибка на одном файле не останавливает остальные, в конце выводится список того, что не скачалось.

## Установка

```bash
git clone https://github.com/Osmanov2006/drivegrab.git
cd drivegrab
pip install .
playwright install chromium
```

## Использование

```bash
drivegrab                     # интерактивно: вставляешь ссылки по одной
drivegrab <ссылка> <ссылка>   # или сразу списком
```

Откроется окно Chromium, его не закрывай. Если нужен вход в аккаунт, залогинься в этом окне и нажми Enter в терминале. Результат сохраняется в `./downloads`.

| Опция | По умолчанию | Что делает |
|---|---|---|
| `-o, --out` | `downloads` | Папка для сохранения |
| `--no-zip` | выкл | Не создавать zip |
| `-q, --quality` | `0.92` | Качество JPEG страниц (0.1–1.0) |
| `--size WxH` | `1920x1080` | Размер окна. Чем больше окно, тем чётче страницы |
| `--profile` | `~/.drivegrab/profile` | Профиль браузера с логином Google |

## Ограничения

- View-only PDF собираются из картинок, поэтому текст в них нельзя выделить или найти поиском. Для этого можно прогнать OCR, например через [ocrmypdf](https://github.com/ocrmypdf/OCRmyPDF).
- Видео и файлы без постраничного превью при закрытом скачивании сохранить не получится.

## Ответственное использование

Скрипт работает только с файлами, которые ты и так можешь открыть в браузере, и права доступа не обходит. Используй его для материалов, которые тебе можно сохранять, и уважай авторские права.
